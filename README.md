# 拾光记账 · Shiguang Ledger

> 把生活记清楚，每一笔，都有迹可循。

A simple personal finance tracker to record income and expenses, view monthly summaries, and understand spending by category. Your data stays in your browser, with easy backup and restore.

拾光记账是一个轻量的个人记账网页，使用原生 HTML、CSS 和 JavaScript 构建。无需注册或安装依赖，即可记录日常收支、查看月度统计，并通过分类环形图了解消费分布。

## 功能

- **日常记账**：记录收入与支出，填写金额、分类、日期和可选备注。
- **月度统计**：按月份查看收入、支出与结余。
- **支出分布**：通过环形图查看各分类的金额与占比。
- **收支明细**：按收入或支出筛选记录，支持确认后删除单笔账目。
- **本地保存**：账目保存在当前浏览器的 `localStorage` 中。
- **备份与恢复**：导出全部月份的 JSON 备份，也可导入备份恢复数据。
- **响应式布局**：适配桌面与手机屏幕。

## 快速开始

### 方式一：直接打开

下载项目，或克隆仓库：

```bash
git clone https://github.com/Doinbjtx/Shiguang-Ledger.git
cd Shiguang-Ledger
```

使用 Chrome、Edge 等现代浏览器打开 `index.html` 即可。请将 `index.html`、`style.css` 和 `app.js` 保存在同一目录。

### 方式二：启动本地服务

如果已安装 Python 3，在项目目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 上也可以使用：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，在终端按 `Ctrl+C` 停止服务。

本项目无需 Node.js、包管理器或构建步骤。

## 使用方法

1. 在「记一笔」中选择收入或支出。
2. 输入金额，选择分类与日期，按需填写备注，点击「保存这笔账」。
3. 在页面顶部切换统计月份，查看汇总、支出分布与明细。
4. 使用明细右上角的筛选项查看不同类型的记录。
5. 定期在页面底部「数据备份与恢复」中导出备份。

首次打开时没有演示数据。添加第一笔支出后即可看到分类图表；添加其他月份的账目时，页面会自动切换至该月份。

## 数据保存与备份

账目仅保存在当前浏览器中，不上传服务器，也不自动跨浏览器或设备同步。项目文件和 Git 仓库不包含浏览器中保存的账目。

- **导出备份**：下载包含全部月份账目的 JSON 文件。
- **导入备份**：选择本项目导出的 JSON 文件，确认后替换全部现有账目。导入前请先导出当前数据。
- **迁移数据**：在原浏览器导出备份，再在新浏览器或新地址中导入。

清理网站数据、使用隐私模式或更换浏览器可能使原账目无法访问。直接打开文件时，浏览器的本地存储行为可能存在差异，移动文件夹也可能影响数据访问；首次使用建议添加一笔记录并刷新页面，确认能够保留。

直接打开 `index.html` 与通过 HTTP 地址访问使用独立的存储空间。不同协议、主机名或端口的地址也使用独立的存储空间，例如 `localhost:8000` 与 `127.0.0.1:8000`。日常使用请保持同一浏览器、用户配置和访问地址，并定期备份。

## 技术与项目结构

使用原生 HTML、CSS 和 JavaScript，无框架、后端、数据库或第三方图表库。支出环形图通过 CSS `conic-gradient` 绘制，金额以整数「分」保存，显示为保留两位小数的人民币金额。

```text
Shiguang-Ledger/
├── index.html       # 页面结构与记账表单
├── style.css        # 页面样式与响应式布局
├── app.js           # 记账、统计、图表、本地存储与备份逻辑
├── 使用说明.md       # 简明使用指南
└── README.md        # 项目介绍
```

如需调整配色和布局，可编辑 `style.css`；收入与支出分类定义位于 `app.js` 顶部的 `categories` 对象中。修改分类前请先备份，并保留历史账目使用过的分类名称，以免影响数据校验与备份恢复。
